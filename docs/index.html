Signal Architecture

Algorithmic Decomposition

Physical camera sensors and optical lenses adhere to physical optics. Generative diffusion and GAN models exhibit mathematical anomalies across frequency and noise domains.

01 / SPECTRAL

2D Fast Fourier Transform

Neural upsampling layers (Transposed Convolutions and PixelShuffle) induce periodic checkerboard artifacts. VerifEye computes a 2D Radix-2 FFT on luminance patches with a 2D Hann window, isolating harmonic peak spikes that exceed local median thresholds by more than 3 standard deviations.

02 / RESIDUAL

Sensor Noise Kurtosis (PRNU)

Optical sensors produce Poisson-Gaussian noise with a characteristic kurtosis near 3.0. Diffusion denoising schedulers create flat surfaces with synthetic micro-grain or unnatural texture smoothing, resulting in extreme kurtosis deviation.

03 / PROVENANCE

Binary Metadata & C2PA Manifests

Directly traverses binary file structures (PNG tEXt/iTXt chunks, JPEG APP segments, XMP packets, and WebP RIFF headers) to detect Automatic1111 prompts, ComfyUI execution graphs, Midjourney parameters, and C2PA cryptographic claims.

04 / COMPRESSION

Error Level Analysis (ELA)

Evaluates 8x8 block discrete cosine transform (DCT) quantization error and variance spread across image partitions to isolate localized composite splices, generative fills, and single-pass neural decoding signatures.

05 / OPTICS

Radial Chromatic Dispersion

Glass camera lenses exhibit wavelength-dependent refractive dispersion at peripheral high-contrast edges. Synthetic neural decoders generate RGB channels concurrently, resulting in hyper-correlated channel boundaries lacking physical optical fringing.

06 / MODES

Tri-Mode Execution Engine

Operate in Local Offline Mode for zero-latency private detection, Hybrid Mode for fast local scans backed by Google Gemini cloud verification, or Cloud API Mode for multimodal evaluation.

Installation

Developer Quickstart

Load unpacked directly in Google Chrome, Brave, Microsoft Edge, or Arc.

Terminal / PowerShell
$ git clone https://github.com/zihaaaad/VerifEye-AI-Image-Detector.git
$ cd VerifEye-AI-Image-Detector
  1. Open your Chromium browser and navigate to chrome://extensions.
  2. Enable Developer mode using the toggle in the upper-right corner.
  3. Click Load unpacked and select the cloned repository folder.
  4. Click the VerifEye toolbar icon to toggle detection ON. Hover over any web image to view instant forensic telemetry.
