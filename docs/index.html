Mathematical Foundations

How VerifEye Detects AI Without Cloud APIs

Generative models do not synthesize pixels according to physical camera optics. VerifEye measures mathematical and structural anomalies directly in the browser.

FFT

2D Fast Fourier Transform

Neural deconvolution and attention upsampling leave periodic checkerboard artifacts. VerifEye computes a 2D Radix-2 FFT on luminance patches with a 2D Hann window, measuring harmonic peak spikes and radial power decay slopes.

PRN

Sensor Noise Residual (PRNU)

Real camera sensors exhibit Poisson-Gaussian shot noise. Diffusion denoising schedulers create unnatural texture oversmoothing. VerifEye uses a 3x3 Laplacian high-pass filter to compute residual kurtosis and flat-region variance ratios.

XMP

Binary Metadata and C2PA

Parses raw binary PNG chunks (tEXt, iTXt), JPEG APP segments, XMP packets, and C2PA Content Credentials manifests for embedded generation prompts, sampler parameters, and algorithmic media declarations.

ELA

Error Level Analysis

Evaluates 8x8 block discrete cosine transform (DCT) quantization boundaries and variance spread to detect synthetic inpainting, face swaps, and single-pass generative decoder profiles.

RGB

Optical Chromatic Dispersion

Physical camera lenses cause subtle radial wavelength dispersion (chromatic aberration) at peripheral high-contrast edges. Synthetic images lack physical lens physics and show hyper-correlated RGB channels.

MOD

Tri-Mode Architecture

Seamlessly switch between Local Offline Engine (private, 0ms network latency), Hybrid Engine (local fast scan + cloud verification), or Cloud API Mode (Google Gemini 1.5/2.0 Flash).

Developer Guide

Install VerifEye in 60 Seconds

Load unpacked directly in any Chromium browser (Google Chrome, Brave, Microsoft Edge, Arc, Opera).

git clone https://github.com/zihaaaad/VerifEye-AI-Image-Detector.git
  1. Open your browser and navigate to chrome://extensions
  2. Toggle Developer mode ON in the top-right corner.
  3. Click the Load unpacked button.
  4. Select the cloned VerifEye-AI-Image-Detector directory.
  5. Click the VerifEye icon in your toolbar to activate the detector. Hover over any image to view instant forensic telemetry.
